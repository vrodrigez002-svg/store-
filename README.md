# Pam's Furniture Shop

E-commerce website for Pam's Furniture Shop, Eldoret, Kenya.
Sells furniture for the living room, dining room, kitchen and bedroom. Delivery countrywide. Payments by M-Pesa.

## Files
- `index.html`: the whole website (pages, styles, scripts and product photos in one file).
